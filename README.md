# Kunal Maurya — Personal Portfolio

A responsive, futuristic portfolio built with React, Vite, and custom CSS.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```
